# PNG 无损智能分割器 v2.2

纯前端、离线运行的透明 PNG 分割 / 居中 / ICO 工具。

## v2.2 新增

- **居中独立开关**：默认勾选；每个输出图块可自动上下 + 左右居中。
- **二维网格自动识别**：支持 2×2、3×3、4×4 等透明间隙图标矩阵，并自动跳过纯空白单元格。
- **手动横切线 + 竖切线**：二维自动检测不准时可以手工补线。
- **ICO 多尺寸包**：默认尺寸 16 / 32 / 48 / 256。
- **ICO 两种模式**：
  - 严格无损：不缩放，只补画布；小于原图的尺寸层自动跳过。
  - 兼容多尺寸：允许高质量缩放，适合 Windows 常规多尺寸 ICO，但明确不属于像素级无损。
- **单文件版**：发布包同时提供一个把 CSS / JS 全部内嵌的独立 HTML，双击即可离线使用；仓库保留模块化源码便于维护。

## “无损”硬规则

默认 PNG 路径：

- 不缩放
- 不重采样
- 不锐化
- 不羽化
- 不重新抠图
- 不把 Alpha 二值化
- 自动检测可忽略 Alpha ≤ 2 噪点，但真正输出边界仍按 **Alpha > 0** 保留
- 居中仅做整数像素平移及透明 / 纯色补画布

> 这里的“无损”指解码后图像像素不因本工具发生缩放或重采样。浏览器会重新编码 PNG，因此不会承诺文件字节、ICC/EXIF/文本元数据与原文件完全相同。

## ICO 说明

### 严格无损 ICO

先把最终 PNG 结果补成正方形，不缩放原内容；再把 PNG 图层封装进 ICO。

- 原始方形边长 > 256px：不允许严格无损 ICO。
- 选中的 ICO 尺寸小于原图：该尺寸层自动跳过。
- 始终保留原始方形尺寸层，并可增加更大的已选尺寸层（只补画布）。

### 兼容多尺寸 ICO

会生成所选 16 / 32 / 48 / 256 等尺寸层，需要缩放重采样，因此必须由用户主动选择。

## 使用

日常使用推荐直接打开发布包里的 `PNG无损智能分割器-v2.2-单文件.html`。

源码模式：打开 `index.html`，并保持 `style.css`、`app.js`、`binary.js` 在同一目录。
