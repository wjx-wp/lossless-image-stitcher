# PNG 无损智能分割器 v2.0

一个纯前端、单文件、离线可用的 PNG 分割与清理工具。面向 UI 图标、透明素材、图标合集等场景，核心目标是：**不缩放、不重采样、不破坏原始 Alpha 抗锯齿边缘**。

## 功能

- 自动识别多个横向分区，不再限制为 2 张。
- 手动添加 / 删除分割线。
- 所有输出自动统一画布尺寸，但不会拉伸内容。
- 自动裁掉透明空白，并统一补透明留白。
- 智能删除每个分区底部的说明文字（基于透明分隔带，不依赖 OCR）。
- 矩形删除、画笔删除、撤销、恢复原图。
- 保持透明背景，或在导出时选择任意纯色背景。
- 单张 PNG 下载，或一次打包为 ZIP。
- 完全离线，图片不会上传到服务器。

## “无损”具体指什么

透明输出模式下，程序使用浏览器 Canvas 的 `getImageData()` / `putImageData()` 直接复制 RGBA 像素；分割、裁边、居中补画布均不执行缩放。

因此，原 PNG 边缘已有的半透明 Alpha 过渡会被原样保留。工具不会主动做：

- 缩放 / 拉伸
- 锐化
- 羽化
- 魔棒重抠
- Alpha 二值化
- JPEG 再压缩

纯色背景输出会把原始 Alpha 按目标颜色正常合成，但同样不会改变几何尺寸或执行缩放。

> 手动矩形/画笔删除会把你选中的像素 Alpha 设为 0。若主动擦到图标本体，擦除边界自然会成为新的硬边；工具不会对这个人为边界做重采样。

## 使用

直接双击 `index.html`，用 Chrome / Edge 打开即可，不需要安装 Python、Node.js 或其他依赖。

1. 拖入 PNG。
2. 点击“自动识别多个分割”。
3. 如有文字，点击“智能删除底部文字”，并检查结果；不满意可“撤销”。
4. 必要时使用“矩形删除”或“画笔删除”。
5. 选择透明或纯色背景。
6. 点击“下载全部 ZIP”。

## 自动分割逻辑

工具扫描整张图的 Alpha 通道，在横向寻找足够宽的“全透明竖向间隙”，将每个间隙的中心作为分割线。可以通过“最小透明间隙”参数控制敏感度。

## 自动删除文字逻辑

工具不会识别具体文字内容，而是在每个分区的下半部寻找“上方主要图形”和“下方小块内容”之间的整行透明带，然后删除透明带下方的内容。这个方式对“图标 + 下方英文/中文标签”的透明素材很有效，同时避免 OCR、字体识别或边缘重建。
