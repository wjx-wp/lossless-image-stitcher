# 无损拼图

这是一款面向大尺寸图片的 Windows 单文件拼接工具。程序不会为了适应画布而缩放原图，适合制作超长竖图、横向连续图以及日常宣传物料。

## 快速使用

1. 将图片文件直接拖入窗口，也可以通过“添加图片”选择一个或多个文件。
2. 使用列表中的勾选框决定哪些图片参与本次拼接；未勾选的图片会保留在列表中，但不会导出。
3. 在列表中按住图片并上下拖动，调整最终拼接顺序。
4. 选择“竖向”可从上到下拼接，选择“横向”可从左到右拼接。
5. 根据需要设置图片在另一方向上的对齐方式、图片间距和画布背景色。
6. 预览确认后导出；程序以 PNG 格式保存结果，避免再次产生 JPEG 压缩损失。

## 带名称合集

勾选需要放入合集的图片，然后点击顶部的“带名称合集”。此模式适合把任意数量的国家海报整理成一张便于浏览和分享的总览图：

- 文件名 `01_Mexico.png` 会自动得到显示名称 `Mexico`。
- 文件名 `02_Saudi_Arabia.png` 会自动得到 `Saudi Arabia`。
- 可以在合集窗口中逐项修改显示名称，不会重命名原始文件。
- 自动排列会根据图片数量和海报比例选择较协调的行数、列数；最后一行不足时会整体居中。
- 也可以关闭自动排列，手动指定列数、单张海报宽度、间距、边距和国家名字号。
- 默认导出 JPEG 质量 92，适合在清晰度和文件大小之间取得平衡；需要更高保真时可选择 PNG。

合集模式会按设置缩小海报并进行高质量重采样，因此它与“原始像素无损拼接”是两个不同用途的模式。所有处理只写入新的合集文件，不会修改原始海报。

## “无损”的含义

本工具所说的“无损”，是指拼接时保留图片解码后的像素，不缩放、不重采样，并将结果写入无损 PNG。若原始文件是 JPEG，它在拍摄或先前保存时已经产生的有损压缩无法恢复；本工具只能保证拼接过程不再增加 JPEG 压缩损失。

间距和对齐产生的空白区域会使用所选背景色填充。不同尺寸的图片不会被强行拉伸成相同宽度或高度。

## 大图与临时文件

- 大尺寸拼图会需要较多磁盘空间和处理时间，请确保导出位置有足够的可用空间。
- 导出过程中如需临时文件，程序只使用唯一的临时名称，并只清理由本次任务创建的文件；不会批量清空图片目录，也不会删除无关文件。
- 发生异常或导出中断时，请确认目标文件是否完整，再重新导出。建议不要让多个程序同时写入同一个目标文件。
- 超长或超宽 PNG 即使已经正确生成，部分旧版看图软件仍可能因自身尺寸或内存限制而打不开。可改用新版浏览器、图像编辑软件或支持大图的查看器确认文件。

## 运行与构建

程序发布为 `dist\无损拼图.exe`，可直接双击运行。它是单个 EXE 文件，不需要另外复制 DLL；Windows 系统仍需具备 .NET Framework 4 运行环境。

如需从源码构建，请在项目目录运行：

```powershell
powershell -ExecutionPolicy Bypass -File .\build.ps1
```

构建脚本只会确保 `dist` 目录存在并写入程序文件，不会清空该目录或其他用户文件。
